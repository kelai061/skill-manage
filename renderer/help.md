# Skill Atelier 使用说明

> 一句话：给它一个智能体产品的启动路径，它把这个产品下所有 skill 找出来，让你浏览、分组、组合、精读、双语对照，并把路径交给智能体。

---

## 1. 第一次使用

1. 打开客户端，它会先问「要不要收录本机已装的工具」——勾选后自动完成扫描；
2. 没有探测到也没关系，去「产品」页点「添加产品」，填一个启动路径，例如：

```
C:\Users\you\AppData\Local\Programs\Antigravity\Antigravity.exe
```

3. 扫描完成后，「全部 Skill」里就是索引结果。

有些商店安装的窗口标题是 ChatGPT，安装身份却是 Codex，会显示为「Codex / ChatGPT 桌面版」。独立的 ChatGPT 安装单独列出。已安装但没有 skill 的产品显示 0；自定义安装目录可以手动添加启动路径。

**只读承诺**：扫描、阅读、翻译、标记全程不写源目录；唯一会写的是你亲手批准的 SKILL.md 改写。

---

## 2. 界面怎么用

| 位置 | 作用 |
|---|---|
| 全部 / 全局 / 项目 / 分组 | 四种视图。项目视图一个项目一张卡，点进去才看 skill；分组视图同理 |
| 搜索框（Ctrl+K） | 按名称、描述、路径、标签搜索 |
| 筛选 ▾ | 未分组、产品、分组、只看收藏、显示嵌套 |
| 右上角「复制给智能体」 | 复制软件目录、skill 索引文件位置与引导语，让智能体按任务挑选 skill |
| 卡片 | 点卡片 = 选中；右下角「阅读」才打开；底部复制按钮复制单个路径 |

**技能集**：一个仓库里套很多 `SKILL.md` 时，整组会收成一张虚线卡，点开才展开；组员可随时「移出嵌套」。

## 3. 阅读与双语对照

阅读器顶栏从左到右：原文 / 并排 / 行间、词间距、目录、字号、朗读全文、更多。

- **并排**：左原文右译文，拖动任意一侧，另一侧跟到同一块的同一位置；
- **行间**：译文以小字缩在每块原文下方，逐句对应；
- **选中同步**：选中一个**单词**，对侧会精确高亮对应的词，并在下方弹出「源词 → 译词」；选中整句则高亮对应句子；
- **标记**：选中文本 → 四色高亮 / 朗读 / 复制 / 备注；
- **朗读**：系统语音合成，不联网。

译文按段落缓存，改一段只重译一段；词级对齐按文件缓存，同一份文档只算一次。

---

## 4. 组合：把 skill 交给智能体

1. 在卡片墙上多选（勾选或 Ctrl+点击）；
2. 底部操作栏「存为组合」；
3. 到「组合」页点「复制路径」，得到：

```
C:\Users\you\.workbuddy-ai\skills\vibestart
C:\Users\you\.workbuddy-ai\skills\code-flowchart
```

粘贴到智能体的项目配置里即可。临时组合会保存在本地，重启后仍可继续使用，也可以清空或存成正式组合。

---

## 5. 附属文件预览

点目录里的附属文件即可查看：

- 图片：直接显示；
- 代码（py / js / ts / json / sh…）：带行号，只读；
- Word（.docx）：抽出正文按排版显示；
- 其他二进制：明确提示不支持，并给「在文件夹中显示」。

非 Markdown 文件不会显示翻译按钮——没有可翻译的正文。

---

## 6. 数据、分享与更新

- **数据位置**：便携版在 `SkillAtelier.exe` 同目录的 `SkillAtelier-data\`；安装版在 `%LOCALAPPDATA%\SkillAtelier\data\`（卸载不会删）；源码运行时在 `%APPDATA%\Skill Atelier\`。都不会进任何 skill 目录；
- **复制给智能体**：右上角按钮复制「软件所在目录 + 一句引导语」，引导语指向同目录下自动生成的 `skills.index.md`（每个 skill 的名称、作用、绝对路径）。索引一变，清单就重写；
- **分享**：设置 → 分享与迁移，导出/导入 JSON 分享包（只合并不删除）；组合可「分享为 Markdown」；
- **更新**：设置 → 关于与更新 → 检查更新（发布源已内置，无需填写）；有新版会在顶栏提示，下载新 exe 替换即可，数据不动。

## 7. 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+K` | 聚焦搜索 |
| `Esc` | 关闭阅读器 / 关闭对话框 |
| `Enter` | 在选中的卡片上打开阅读器 |

## 8. 常见问题

**Q：扫描不到 skill？**
确认目录里有 `SKILL.md`（大小写不敏感）；也可以直接把某个 skill 目录当「启动路径」填进去。

**Q：翻译失败？**
检查设置里的 Base URL / API Key / 模型；点「测试连接」会真的发一次请求。

**Q：改写会不会覆盖我的文件？**
不会。AI 只能生成提案，必须逐行审阅后点「批准」；写入前自动备份，文件被外部改动过会中止。

**Q：词级高亮有时只亮整句？**
模型没有覆盖那个词时会退回句子级——不会没有反馈。可以在「更多 → 重新翻译」后重试。
