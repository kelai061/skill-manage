快速开始

两种方式任选：下载单个 exe 双击运行；或从源码启动。

git clone https://github.com/kelai061/skill-manage.git
cd skill-manage
npm install
npm start

首次启动会探测本机已装的智能体工具（WorkBuddy / Antigravity / Claude Code / Cursor…），勾选即收录。也可以手动在「产品」页填一个启动路径：

C:\Users\you\AppData\Local\Programs\Antigravity\Antigravity.exe

扫描、阅读、翻译、标记全程只读；唯一会写的是你亲手批准的 SKILL.md 改写。

核心能力

◎

路径即入口

只填一次启动路径，自动推导候选根并递归发现 skill；也能从工具自己的数据库里读出项目。

▦

卡片即索引

全部 / 全局 / 项目 / 分组四种视图；嵌套 skill 收成技能集，点开才展开。

⇄

双语对照

并排与行间两种模式，滚动双向同步；选中一个单词，对侧精确高亮对应的词。

⌘

组合复制

把常用 skill 组成清单，一键复制每行一条绝对路径，直接粘给智能体。

◫

什么都能看

图片直接显示、Word 抽正文、代码带行号；不支持的格式明确说原因。

✓

授权才写

AI 只能生成提案，逐行 diff 审阅后批准；写入前备份、原子替换、全程审计。

卡片与分类

卡片墙是工作台：点卡片是选中，右下角「阅读」才打开。顶部分段控件切换范围，筛选收进一个菜单，不堆一长排按钮。

全部 Skill · 86 个（另有 140 个已折叠进技能集/父级）
全部 86全局 53项目 33分组 4
技能集 · agent-rules-books28 个
code-flowchart全局
obsidian-file-color项目

技能集：一个仓库里套很多 SKILL.md 时，整组收成一张虚线卡，点开才展开；组员随时可以「移出嵌套」，决定记在配置里，重扫不丢。

项目：一个项目一张卡，默认折叠——总览里不铺 skill，点卡才进去；0 个 skill 的项目也列出，右侧给「＋」新建。

双语对照，精确到词

翻译按段落对齐，滚动位置换算成「第几块的百分之几」再落到另一栏，误差不会累积。

并排模式原文 / 并排 / 行间
The builder writes weekly summaries for the community.
这位构建者每周撰写摘要，面向社区。

选中一个单词，对侧会精确高亮对应的词，并在下方弹出 源词 → 译词；选中整句则按句子映射。词对由模型给出并做字面校验，定位不到就退回句子级——不会出现「选了没反应」。

  • 译文按段落缓存：改一段只重译一段；
  • 词对齐按文件缓存：同一份文档只算一次；
  • 支持四色标记、朗读选中/全文，全部本地完成。

文件预览

阅读器里的附属文件按类型渲染，不会把二进制当文本读成一屏乱码。

类型展示
图片（png / jpg / gif / webp / svg）直接显示
代码（py / js / ts / json / sh…）带行号，只读
Word（.docx）抽出正文按排版显示
其它二进制说明原因 + 在文件夹中显示

组合与分享

组合就是一份路径清单：多选 skill → 存为组合 → 复制，得到每行一条绝对路径，直接粘进智能体的项目配置。

C:\Users\you\.workbuddy-ai\skills\vibestart
C:\Users\you\.workbuddy-ai\skills\code-flowchart

右上角还有「复制路径」：不用先多选，直接把当前筛选结果（或已选中的）复制成清单。组合也能「分享为 Markdown」，发给同事照着装。

换电脑时用「导出分享包」：产品、项目、分组、组合、收藏、评分打成一份 JSON，导入只合并、不删除。

数据与隐私

  • 数据全部在 %APPDATA%\Skill Atelier\，不进任何 skill 目录；
  • 读取 agent 工具数据库时先复制快照，不在对方目录留下 -wal / -shm；
  • 分享包不含译文、标记与源文件；
  • 更新检查只请求 GitHub 的 latest release，不上报使用数据。

常见问题

扫描不到 skill？

确认目录里有 SKILL.md（大小写不敏感）；也可以直接把某个 skill 目录当「启动路径」填进去。

翻译失败？

检查设置里的 Base URL / API Key / 模型，点「测试连接」会真的发一次请求。

AI 会不会改坏我的文件？

不会。AI 只能生成提案，必须逐行审阅后点「批准」；写入前自动备份，文件被外部改动过会中止。

词级高亮有时只亮整句？

模型没有覆盖那个词时会退回句子级，不会没有反馈。可以在「更多 → 重新翻译」后重试。

支持 macOS / Linux 吗？

目前只打包了 Windows 单文件便携版；代码本身是 Electron，跨平台移植主要是打包配置的工作。
